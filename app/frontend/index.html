System Design Topology

FloraGuard End-to-End Deep Learning & Guardrail Pipeline

End-to-End Diagnostic Architecture: Full operational dataflow from client leaf ingestion, through FastAPI async gateways and dual-tier bio-optical / neural guardrails, to PyTorch accelerated inference and agronomic treatment synthesis.

⚙️ Detailed Engineering Dataflow: From Raw Pixel Ingestion to Agronomic Cure

How FloraGuard connects the web frontend, asynchronous backend gateway, bio-optical tensor preprocessing, and hardware-accelerated deep neural networks:

Step 01 FastAPI • httpx
Data Ingestion & Gateway

Receives user image inputs through two production ingestion pathways:

  • File Upload: Multipart form data (JPEG/PNG) via POST /api/predict.
  • Web URL Ingestion: Public link via POST /api/predict-url fetched asynchronously with httpx.AsyncClient (10MB safety cap).
  • Buffer Decoding: Raw byte stream unpacked into a PIL Image buffer enforced in strict RGB color space.
Step 02 TorchVision • Bio-Optics
Bio-Optical Preprocessing

Protects the model from out-of-distribution junk and standardizes tensors:

  • Tier-1 Guardrail: Bio-optical foliage filter analyzes chlorophyll green and carotenoid/necrotic chrominance in HSV space; instantly drops UI screenshots, code, and non-organic objects before GPU compute.
  • Spatial Scaling: Bicubic resize to 256×256 pixels followed by CenterCrop to 224×224.
  • Tensor Standardization: ToTensor() maps [0, 255] to [0.0, 1.0], normalized with ImageNet stats ($\mu=[0.485, 0.456, 0.406]$, $\sigma=[0.229, 0.224, 0.225]$).
Step 03 PyTorch • MPS/CUDA
Neural Engine & ModelManager

Dispatches batch tensor $(1, 3, 224, 224)$ to hardware accelerator:

  • Hardware Acceleration: Auto-detects Apple Silicon (MPS), NVIDIA GPUs (CUDA), or optimized multi-core CPU.
  • ModelManager Singleton: Hot-swaps backbones without server restarts (MobileNetV3 99.84%, ResNet-18 99.83%, ViT 99.68%, Custom CNN 99.46%).
  • Forward Pass: Evaluated under torch.no_grad() with Softmax yielding posterior probabilities across 38 pathogen classes.
Step 04 Tier-2 OOD • Knowledge Base
Confidence Gate & Agronomy

Ensures diagnostic safety and synthesizes actionable clinical advice:

  • Tier-2 Guardrail: Neural confidence check flags predictions with Top-1 probability < 50% as Low Confidence / Out-of-Distribution.
  • Top-5 Margin: Calculates uncertainty delta between 1st and 2nd candidate diagnoses.
  • Agronomic Synthesis: Maps class to disease_info.py database for pathogen etiology and 3-tier treatment (Cultural, Organic, Chemical).
Step 05 Vanilla JS • Glassmorphism
Reactive Client Presentation

Renders structured clinical diagnostic payload in real-time:

  • JSON Envelope: Transmits disease name, confidence score, pathogen type, treatment plan, and server latency telemetry.
  • Visual Triage: High-contrast severity badge, animated confidence meter, and Top-5 candidate probability bars.
  • Action Tabs: Farmers access tabbed recommendations for Cultural sanitation, Organic biocontrols, and targeted Chemical fungicides.
🥇 Benchmark Winner • Edge Champion

MobileNetV3-Large

Depthwise Separable Convolutions & Squeeze-and-Excitation Attention

Parameters: 4,250,710 (4.25M)
Disk Footprint: 16.22 MB
Trained Epochs: 18 Epochs
Test Acc / Macro-F1: 99.84% / 0.9977

Achieved highest overall generalization on our unseen 5,431 leaf test set. Depthwise separable convolutions reduce FLOPs by ~80% while retaining spatial diagnostic resolution through Squeeze-and-Excitation channel gating and computationally efficient Hard-Swish activations.

🥈 Transfer Learning Workhorse

ResNet-18 Deep Residual

Skip-Connection Residual Network Fine-Tuned for Botanical Diagnosis

Parameters: 11,196,006 (11.2M)
Disk Footprint: 42.71 MB
Trained Epochs: 18 Epochs
Test Acc / Macro-F1: 99.83% / 0.9976

Leverages residual skip connections to eliminate vanishing gradients across deep representations. Fine-tuned with AdamW weight decay (1e-4) and Cosine Annealing, achieving near-perfect 99.83% test accuracy across all 38 plant pathogen classes.

🥉 Vision Transformer

google/vit-base-patch16-224

Self-Attention Patch Transformer Across 16×16 Visual Tokens

Parameters: 85,827,878 (85.8M)
Disk Footprint: 327.41 MB
Trained Epochs: 5 Epochs (Best: Ep 3)
Test Acc / Macro-F1: 99.68% / 0.9964

Discards convolutions entirely in favor of multi-head self-attention across 196 non-overlapping 16×16 pixel patches. Global self-attention enables the network to correlate localized necrotic spots with systemic leaf curling from layer 1.

Trained From Scratch

Custom PlantDiseaseCNN

4-Stage Deep Convolutional Hierarchy with Aggressive Regularization

Parameters: 541,478 (0.54M)
Disk Footprint: 2.07 MB
Trained Epochs: 24 Epochs
Test Acc / Macro-F1: 99.46% / 0.9916

Engineered from first principles without external weights. Employs 4 convolutional blocks (32 ➔ 64 ➔ 128 ➔ 256 channels), Batch Normalization after every convolution, and 50% dropout. Attained 99.46% test accuracy with an ultra-compact 2.07 MB footprint.

🔬 Empirical Hyperparameter Optimization (8 Trials)

Ablation Study

Before full training, an automated grid search evaluated optimizer dynamics, learning rates, and dropout rates on the Custom CNN:

⚡ Optimizer Rationale: AdamW vs SGD

In our 2-epoch trials, AdamW achieved 86.80% validation accuracy, outperforming momentum SGD (61.22%) by +25.6 percentage points. Decoupled weight decay prevented gradient explosion on complex leaf textures and converged 3× faster.

🛡️ Dropout Regularization: 0.5 vs 0.3

Increasing dropout from 0.3 to 0.5 in the dense classification head yielded superior generalization (Val F1 0.818 vs 0.811), successfully preventing the network from overfitting to background soil and petri dish artifacts in the dataset.

🔒 2-Tier Out-of-Distribution (OOD) Guardrail

To solve the classic "closed-set classifier" flaw where non-leaves or computer screenshots are misclassified, FloraGuard integrates a bio-optical foliage filter (analyzing chlorophyll green / carotenoid chrominance) and a neural confidence threshold to block false predictions.
