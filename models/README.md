# Model Checkpoints Directory

Trained deep learning model checkpoints are stored in this directory:

- `custom_cnn_best.pt` — Custom 4-block CNN trained from scratch (99.48% Val Accuracy)
- `resnet18_best.pt` — ResNet-18 Transfer Learning model (99.84% Val Accuracy)
- `mobilenet_best.pt` — MobileNetV3-Large Edge-optimized model
- `huggingface_vit_best.pt` — Fine-tuned Vision Transformer (ViT-Base/16)

> **Note**: Heavy binary `.pt` files (>100MB) are excluded from GitHub git tracking per GitHub's 100MB file limit policy. Checkpoints can be generated by running the experiment scripts in `experiments/` on Google Colab or downloaded from project releases.
